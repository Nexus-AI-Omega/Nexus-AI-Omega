### 🚀 About Me

I'm **Jan Wolf**, a developer from **Frankfurt am Main, Germany** building at the intersection of **mobile graphics, AI and community platforms**.

- 🎮 **NexusGrid** — Custom GL implementation on top of **OpenGL ES 3.x** that runs **Minecraft: Java Edition + shaders (Iris/OptiFine)** on Android. Includes GLSL ES translation, MultiDraw optimization, FSR1 upscaling and **Geyser + Floodgate** Bedrock crossplay.
- 🤖 **Nexus AI Omega** — Production Discord bot with **~100 slash-commands**, **14 AI providers** (OpenAI, Claude, Gemini, Groq, Mistral...), tickets, economy, music, moderation, support-voice & Zero-Trust security — **TypeScript • Node 22 • Prisma • Redis • Kafka**
- 🛠️ Passionate about **C++ / NDK / Kotlin / Jetpack Compose** and high-performance mobile rendering.
- 📍 Based in Frankfurt, open for collaborations & freelance.

> “Empowering mobile gaming — Java should run everywhere.”
